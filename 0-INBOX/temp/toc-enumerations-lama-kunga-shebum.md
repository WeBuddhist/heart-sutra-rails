Enumeration Block 1:
འདི་ལ་སྤྱི་དོན་རྣམ་པ་བཞིས་སྟེ། བསྒྲུབ་བྱ་རང་གི་ངོ་བོ་ངོས་བཟུང་བ་བསྟན་པ་དང་། །གླིང་གཞིའི་བརྒྱུད་པའི་བཀའ་བབས་དང་བཅས་ཏེ་བཤད་པ་དང་། །སྙིང་པོ་དེའི་དོན་དངོས་བསྟན་པ་དང་། །ཕ་རོལ་ཏུ་ཕྱིན་པ་བཙལ་བའི་རིམ་པ་ཁ་བསྐངས་ཏེ་བསྟན་པའོ། །བསྒྲུབ་བྱས་རང་གི་ངོ་བོ་ངོས་བཟུང་ལ་བཞི། གང་གསུངས་པའི་ཆོས་ངོས་བཟུང་བ་དང་། གང་གིས་གསུངས་པའི་སངས་རྒྱས་ངོས་བཟུང་བ་དང་།  ཇི་ལྟར་གསུངས་པའི་ཚུལ་ངོས་བཟུང་བ་དང་། གང་བཤད་པའི་གཞུང་གི་ངོ་བོ་ངོས་བཟུང་བ་དང་བཞིའོ། །
Enumeration Block 2:
གསུམ་པ་ཆོས་འདི་ཇི་ལྟར་གསུངས་པའི་ཚུལ་ངོས་བཟུང་བ་ལ་ཡང་གཉིས། རང་དོན་གཅོད་ཀྱི་རྩ་བར་རྟོགས་པ་མངོན་དུ་གྱུར་ནས། ཆོས་ཀྱི་སྐུར་སངས་རྒྱས་པ་དང་། གཞན་དོན་བསྐྱེད་ཀྱི་རྩ་བར་གཟུགས་ཀྱི་སྐུར་བཞེས་ནས་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བའོ། །
Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:
གཉིས་པ་ཐུན་མོ་མ་པའི་གླེང་གཞི་ལ་གཉིས་ཏེ། གདན་བཤམ་པ་དང་། ཆོ་འཕྲུལ་བགྱེ་བའོ། །
Enumeration Block 6:
གཉིས་པ་ཆོ་འཕྲུལ་བགྱེ་བ་ལ་གསུམ་སྟེ། ཏིང་ངེ་འཛིན་གྱི་ཆོ་འཕྲུལ་དང་། རྫུ་འཕྲུལ་གྱི་ཆོ་འཕྲུལ་དང་། ཆོས་སྣང་བའི་ཆོ་འཕྲུལ་ལོ། །ཏི་ངེ་འཛིན་གྱི་ཆོ་འཕྲུལ་ལ་གཉིས་ཏེ། ཏིང་ངེ་བ་འཛིན་གྱི་རྒྱལ་པོ་དང་། སེང་གེ་རྣམ་པར་རོལ་བའོ། །ཏིང་ངེ་འཛིན་གྱི་རྒྱལ་པོ་ལ་བཞི་སྟེ།

Enumeration Block 8:
གསུམ་པ་ཆོས་སྣང་བའི་ཆོ་འཕྲུལ་བསྟན་པ་ནི་གཉིས་ཏེ། འཁོར་བསྡུ་བ་དང་ཆོས་སྣང་བ་དངོས་སོ། །དང་པོ་ལ་གསུམ་སྟེ། ལྷའི་རིགས་བསྡུ་བ་དང་། སངས་རྒྱས་ཀྱི་ཞིང་ཁམས་གཞན་ནས་བསྡུ་བ་དང༌། མིའི་རིགས་ནས་རིགས་སུ་བསྡུ་བའོ། །
