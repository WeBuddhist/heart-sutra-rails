Enumeration Block 1:
འདི་འཆད་པ་ལ་བསྡུས་པའི་དོན་གསུམ། མཚན་དོན། གཞུང་དོན། མཇུག་དོན་ནོ། །
Enumeration Block 2:
གཉིས་པ་གཞུང་དོན་བཤད་པ་ལ་གསུམ། ཐོག་མར་གླེང་གཞི་རྗེས་སུ་གནང་བའི་བཀས་མདོར་བསྟན་པ། བར་དུ་གླེང་བསླང་དངོས་བྱིན་གྱིས་རླབས་པའི་བཀས་རྒྱས་པར་བཤད་པ། མཐར་མར་གྲུབ་དོན་ཞལ་ནས་གསུངས་པའི་བཀས་མཇུག་སྡུད་བསྟན་པའོ། །
Enumeration Block 3:
གཉིས་པ་བར་དུ་གླེང་བསླང་དངོས་བྱིན་གྱིས་བརླབས་པའི་བཀའ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། གང་གིས་བྱིན་གྱིས་རློབས་པར་བྱེད་པའི་ཏིང་ངེ་འཛིན། གང་ལ་བྱིན་གྱིས་བརླབ་པར་བྱ་བའི་གང་ཟག །​དྲི་བ་དང་དྲི་ལན་ཇི་ལྟར་མཛད་པའི་ཚུལ་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སྤྱན་རས་གཟིགས་ལ་བྱིན་གྱིས་རློབ་ཚུལ་དང་། ཤཱ་རིའི་བུ་ལ་བྱིན་གྱིས་རློབ་ཚུལ་ལོ། །
Enumeration Block 5:
གསུམ་པ་དྲི་བ་དང་དྲི་ལན་ཇི་ལྟར་མཛད་པའི་ཚུལ་བཤད་པ་ལ་གཉིས། དྲི་བ་མདོར་བསྟན་པ་དང་ཡང་ལན་རྒྱས་པ་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ཡང་ལན་རྒྱས་པར་བཤད་པ་ལ་བཞི། ལྟ་བའི་ངོ་བོ། སྒོམ་པའི་གནད། འབྲས་བུའི་ས། སྤྱོད་པའི་གསེང་ལམ་བཤད་པའོ། །​དང་པོ་ལ་གསུམ། ངོ་བོ་སྟོང་པ་ཉིད། རྒྱུ་མཚན་མ་མེད་པ། འབྲས་བུ་སྨོན་པ་མེད་པའོ། །​དང་པོ་ལ་གཉིས། ངོ་བོ་མདོར་བསྟན་པ་དང་། དབྱེ་བ་རྒྱས་པ་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་དབྱེ་བ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཕུང་པོའི་དེ་ཉིད་བཞིར་དབྱེ་བ་དང་། ཆོས་ཀྱི་རང་བཞིན་བརྒྱད་དུ་དབྱེ་བའོ། །
Enumeration Block 8:
གཉིས་པ་རྒྱུ་མཚན་མ་མེད་པའི་རྣམ་པར་ཐར་པ་བསྟན་པ་ལ་གསུམ། ཕུང་པོ་ལྔ། སྐྱེས་མཆེད་བཅུ་གཉིས། ཁམས་བཅོ་བརྒྱད་བཅས་མཚན་མ་མེད་པར་བསྟན་པའོ། །
Enumeration Block 9:
གསུམ་པ་འབྲས་བུ་སྨོན་པ་མེད་པའི་རྣམ་པར་ཐར་པ་བསྟན་པ་ལ་གསུམ། གཞི་འཁོར་འདས་ཀྱི་རྟེན་འབྲེལ། ལམ་འཕགས་པའི་བདེན་པ་བཞི། འབྲས་བུ་སངས་རྒྱས་ཀྱི་ཡེ་ཤེས་བཤད་པའོ། །
Enumeration Block 10:
བཞི་པ་སྤྱོད་པའི་གསེང་ལམ་བཤད་པ་ལ་གཉིས། འདི་སྔགས་ཀྱི་ལམ་དུ་བསྟན་པ་དང་། འདི་ལ་སློབ་པར་གདམས་པའོ། །​དང་པོ་ལ་གཉིས། སྔགས་ཀྱི་བྱེད་ལས་བསྟན་པ་དང་། སྔགས་དོན་བཤད་པའོ། །
